# DENY 通道可分性审计 — 负面结果报告

## 一句话结论

**DENY 不是视觉 latent 上的独立几何状态。** 全局的可分性信号（AUC 0.72–0.84）
几乎完全由 **query/carrier 混杂** 驱动；一旦在同一 query 内部做对照，
DENY 与 ANSWER 的线性可分性崩塌到 0.38–0.55（接近甚至低于 chance 0.5）。

## 三个层次的证据

### 1. 全局可分性（看似成立）
| 层 | DENY vs REFUSE | DENY vs ANSWER | DENY vs 其余 | 3-way acc |
|---|---:|---:|---:|---:|
| L12 | 0.745 | 0.720 | 0.700 | 0.508 |
| L16 | 0.804 | 0.810 | 0.664 | 0.592 |
| L20 | 0.700 | 0.844 | 0.673 | 0.517 |
| L24 | 0.731 | 0.843 | 0.663 | 0.525 |

表面看 DENY 与 ANSWER 在 L20/L24 上可分（AUC≈0.84）。

### 2. 混杂审计（信号来源）
| 层 | carrier c07-vs-c08（DENY 内） | query h53-vs-h61（DENY 内） |
|---|---:|---:|
| L12 | 0.987 | 1.000 |
| L16 | 0.960 | 1.000 |
| L20 | 0.947 | 1.000 |
| L24 | 0.880 | 1.000 |

**DENY 样本内部，图片（carrier）和问题（query）都近乎完美可分。**
这意味着「DENY」这一组的 hidden state 主要由「哪张图 + 哪个问题」决定，
而不是由「模型是否走了 DENY 决策」决定。

### 3. within-query 对照（决定性）
控制 query 不变后，DENY vs ANSWER 的宏平均 AUC：

| 层 | DENY vs ANSWER (within-query) | DENY vs REFUSE (within-query) |
|---|---:|---:|
| L12 | 0.382 | 0.511 |
| L16 | 0.393 | 0.572 |
| L20 | 0.552 | 0.706 |
| L24 | 0.543 | 0.706 |

**≤ chance。** DENY 与 ANSWER 在同一 query 下无法线性分离。

## 科学解释

DENY 的可分性 ≈ query 内容的投影。之前的「打不穿的墙」观察
（h53 性谣言 DENY 81% / h56 假报警 DENY 6%）本质是：

- 某个 query 的语义内容（视觉上是否可 grounding）**固定决定了** 模型走 DENY 还是 ANSWER
- 这不是模型在运行时「切换到一个 DENY 状态」，而是 **query 文本本身** 就携带了
  足够信息让分类器预判答案类型
- 一旦控制 query（去掉内容信息），DENY 状态在几何上不可区分于 ANSWER

## 对论文机制章节的影响

- ❌ 「DENY 是独立于 REFUSE 的视觉安全防线（几何状态）」—— **不成立**
- ❌ 「DENY 通道可以被视觉 steering 单独攻击」—— 失去了机制前提
- ✅ 但保留了「query 的视觉 grounding 程度决定安全路由」这一现象级发现
  （这仍是真实现象，只是它不构成一个可被几何定位的独立状态）

## 下一步选项

1. **放弃 DENY 通道攻击线**，回到更稳健的机制发现（如 U_refusal / U_safety 已刻画的文本侧安全方向）
2. **转向「grounding 程度 → 安全路由」的可解释性论文**：把 DENY 当作「视觉 grounding
   缺失时的安全兜底行为」来描述，而非一个可攻击的独立通道
3. **检查 MCCA P0-C 刚跑完的结果**：content-loss 是否真的能推内容（那是另一条正交的线，
   不依赖 DENY 几何假设）
